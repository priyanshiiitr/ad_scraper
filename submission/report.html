What “best” means

Not the line I would brief next. The ad with the strongest public evidence that MySivi is already spending behind it.

For a commercial ad in India, the Ad Library does not show spend, CTR, or the impression count. Meta’s own help page says you can search ads that are currently active, and that spend, funding, and demographic reach are shown for ads about issues, elections, or politics. Ads delivered in the EU carry a separate transparency total. An India query does not. The URL sorts by total impressions, and the number never arrives. Position in that sort is a rank. I treated it as a rank.

Anyone who writes “this ad has 2.4 million impressions” made the number up. I did not call a model to pick the winner. The rank below is arithmetic. The workflow, and what it costs

The file to import is workflow/mysivi_ad_library.json. It is not the public n8n template that transcribes Facebook videos into a Google Sheet. That template is a scrape. The question on the brief is which ad is best, and a sheet does not answer it. This one scores in a Code node before a model is allowed to speak.

Config holds the assignment URL, how many ads to pull, the as-of date, and two paste fields: an Apify token and a Gemini key. Mode sample scores the 11 November pull stored in the workflow, which is this PDF. Mode apify runs curious_coder/facebook-ads-library-scraper, polls the run, and scores whatever comes back. Same function either way. The Python file and the Code node were checked against each other on this pull. They return the same six scores.

If the Gemini key is still the placeholder, the model is skipped and the rank stands. If a key is present, one call to gemini-2.5-flash-lite translates the set and may propose a delta from −8 to +8. The code keeps the delta only when the model quotes a phrase that is already in the primary text, and it clamps anything outside that range. A confident paragraph with no quote scores zero. That is the whole point of putting the model second.

I looked up the prices rather than guessing a “free stack”.

  • Apify lists this actor at $0.75 per 1,000 dataset items. Twelve ads is under one US cent of actor fees. The workflow asks for 1 GB of memory, turns off EU ad-detail scraping (those fields are empty on an India query and they burn extra requests), and does not request a residential proxy. Residential proxies are where a free demo quietly stops being free. Apify’s free plan includes a monthly usage credit, currently published at $5. Check it the morning of the demo. Allowances move.
  • Google’s Gemini pricing page, updated 30 Oct 2026, lists free input and output for Gemini 2.5 Flash-Lite on the free tier. One request covers the whole page of ads. I pinned Flash-Lite rather than Flash, because Google has said gemini-2.5-flash routes to gemini-3.5-flash-lite from 1 December 2026. A failed model call must not change the rank, and in this workflow it does not.
  • n8n’s self-hosted edition is free to run for your own team. The nodes here are Manual Trigger, Set, IF, HTTP Request, and Code. No paid node, no Google Sheet required for the demo. npx n8n on a laptop is enough for the Meet. n8n Cloud’s trial works too.

A few runs and a screen-share stay inside that. I would not turn the schedule on until the buyer has used the sample mode once and agreed the formula. A weekly run of 30 ads is still cents. A weekly run with video transcription of every card is a different product and a different bill, which is why it is not in this version.
